# MeArm sim

Open `index.html` straight from Finder, no server or internet needed.

MeArm (4× SG90) on the BLACKOUT roof: joint sliders, pick demo, three mount options
(roof front edge, roof center, low front bracket), servo holding load and rover collision check.

Arm geometry + joint coupling: [kubasikora/mearm_model](https://github.com/kubasikora/mearm_model) (URDF and part meshes are inlined in the page).
three.js r147 classic builds in `vendor/`.
